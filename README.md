# 【电光独龙钻Electro-Dragon Drill】
## 电光独龙钻是一套基于ESP32-C3 Super Mini主控搭建的连续旋转一维激光扫描雷达。使用6.5mm四线导电滑环解决旋转端传感器线束缠绕问题，搭配AS5600磁编码器获取转轴角度，通过一阶傅里叶谐波拟合补偿磁铁偏心误差；VL53L0X激光测距模块跟随扫描头同步旋转，同步采集角度+距离，输出极坐标点云，可在上位机绘制二维扫描轮廓
## Electro-Dragon Drill is a continuous rotating Two-dimensional laser scanning radar based on ESP32-C3
